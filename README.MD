# 탐험대 운영 시스템

Python으로 만든 터미널 기반 탐험대 운영 프로그램입니다.

캐릭터를 생성하고 관리할 수 있으며, 인벤토리 관리, 탐험 시스템, 저장/불러오기, 설정, 로그 기능 등을 포함합니다.

외부 날씨 API를 사용해 현재 날씨에 따라 탐험의 위험도가 달라지도록 구현했습니다.

---

## 주요 기능

### 캐릭터 관리
- 캐릭터 생성
- 전체 캐릭터 조회
- 특정 캐릭터 검색
- 캐릭터 삭제
- HP, 공격력, 골드 관리

### 인벤토리
- 아이템 지급
- 아이템 제거
- 캐릭터별 인벤토리 조회

### 탐험 시스템
- 여러 탐험 지역 제공
- 탐험별 추천 공격력, 위험도, 골드 보상 설정
- 캐릭터 능력치에 따른 성공 확률 계산
- 성공 시 골드 보상 지급
- 성공/실패 상태 관리

탐험 성공 확률은 캐릭터의 HP와 공격력, 탐험의 위험도와 추천 공격력을 이용하여 계산됩니다.

### 날씨 API
Open-Meteo API에서 현재 날씨 정보를 받아옵니다.

날씨 상태에 따라 추가 위험도가 적용되며, 악천후일수록 탐험 성공 확률이 낮아집니다.

API 요청에 실패하더라도 기본 위험도를 사용하여 게임을 계속 실행할 수 있도록 구성했습니다.

### 저장 및 불러오기
- JSON 기반 캐릭터 데이터 저장
- 프로그램 재실행 시 데이터 복원
- 일부 손상된 데이터에 대한 예외 처리
- 세이브 버전 확인

### 설정
- 자동 저장 ON/OFF
- 캐릭터 삭제 확인 ON/OFF
- 설정값 JSON 저장

### 로그
`game.log` 파일에 주요 동작을 기록합니다.

예:
- 캐릭터 생성 / 삭제
- 아이템 지급 / 제거
- 탐험 시작 / 성공 / 실패
- 저장 / 불러오기
- 오류 및 경고

## 파일 구조

```text
New_RPG/
├── start.py
├── Guild.py
├── character.py
├── expedition.py
├── API.py
├── requirements.txt
├── README.md
├── .gitignore
└── .env
```

### start.py
프로그램 실행 및 CLI 메뉴를 담당합니다.

### Guild.py
`Game` 클래스를 포함하며 캐릭터, 인벤토리, 탐험, 저장, 설정 등의 전체 시스템을 연결합니다.

### character.py
`Character` 클래스와 캐릭터별 데이터 및 인벤토리 기능을 담당합니다.

### expedition.py
`Expedition` 클래스, 탐험 데이터, 탐험 성공 판정 및 보상 시스템을 담당합니다.

### API.py
Open-Meteo API에 요청하여 현재 날씨 코드를 가져옵니다.

## 설치

필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

`requirements.txt`:

```text
requests
python-dotenv
```

## 환경 변수

프로젝트 폴더에 `.env` 파일을 만들고 다음 값을 설정합니다.

```env
API_URL=https://api.open-meteo.com/v1/forecast
```
